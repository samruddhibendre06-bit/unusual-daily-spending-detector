# Unusual Daily Spending Detector

## Project Overview
This project uses Machine Learning to identify potentially unusual household spending transactions using the Isolation Forest algorithm.

## Algorithm
Isolation Forest — Unsupervised Machine Learning.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Dataset
Daily Household Transactions dataset containing household income and expense records.

## Results
- Expense transactions analysed: 1,199
- Normal transactions: 1,139
- Unusual transactions detected: 60
- Unusual transactions flagged: approximately 5%

## Project Files
- `Untitled2.ipynb` — Project code and implementation.
- `spending_detection_results.csv` — Results of anomaly detection.

## Conclusion
The project demonstrates how unsupervised machine learning can help identify unusual spending patterns. Flagged transactions may require review and are not necessarily incorrect or fraudulent.
